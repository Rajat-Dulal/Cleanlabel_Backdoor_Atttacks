# Data

Nothing large is committed (see `.gitignore`). Everything is regenerated by the scripts:

| Item | Source / how produced | Location |
|---|---|---|
| CIFAR-10 (train 50k / test 10k) | auto-downloaded by `torchvision` via `src/shared_utils/data.py` | `data/cifar-10-batches-py/` |
| Pretrained DDPM | `google/ddpm-cifar10-32` from the HuggingFace Hub (cached in `~/.cache/huggingface`) | - |
| Phase 2 poisons | `generate_poisons.py` | `data/poisons/<base>2<target>_t<t>_g<g>_n<n>_s<seed>.{pt,json,png}` |
| Phase 2 surrogate (5-conv CNN) | trained on first use | `data/checkpoints/surrogate.pt` |
| Clean / poisoned victims | `train_target_cnn.py`, `run_sweeps.py` | `data/checkpoints/victim_*.pt` |
| Phase 1 surrogate / victim (ResNet-18) | `train_and_poison.py` | `data/checkpoints/sit723_*.pth` |

CIFAR-10 "subset used": the full 50,000-image training split is used; poisons **replace** images at the same
index (dataset size unchanged). The poison-generation pools are the 5,000 cat training images (Phase 2) / 5,000 dog
training images (Phase 1), and the target images come from the test split.
